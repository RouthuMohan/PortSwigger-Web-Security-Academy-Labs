# File Path Traversal

Welcome to my File Path Traversal learning repository based on the **PortSwigger Web Security Academy**.

This section documents my hands-on practice, including vulnerability analysis, traversal techniques, payloads, testing methods, and lab solutions.

## Learning Objectives

- Understand File Path Traversal vulnerabilities.
- Identify vulnerable file-handling parameters.
- Understand different traversal techniques and bypass methods.
- Practice manual testing using Burp Suite.
- Understand the security impact and prevention techniques.
