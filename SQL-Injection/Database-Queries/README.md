# Database Queries

This folder contains database-specific SQL syntax, system tables, functions, and SQL Injection payloads commonly used during Web Application Penetration Testing.

Different Database Management Systems (DBMS) use different SQL syntax.

Understanding these differences is essential when performing SQL Injection attacks or solving PortSwigger Web Security Academy labs.

## Supported Databases

- MySQL
- PostgreSQL
- Oracle
- Microsoft SQL Server
- SQLite

Each file explains:

- Database identification
- Version queries
- Current database
- Current user
- System tables
- UNION SELECT payloads
- Enumeration queries
- Useful SQL Injection payloads
